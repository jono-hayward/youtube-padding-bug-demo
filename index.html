This page shows the page in cover mode, which is an optional setting some sites use to make their page layout look more natural on a mobile device screen. In this mode, the YouTube iframe automatically applies internal padding using CSS env(safe-area-inset-*) variables, designed to push content away from the rounded corners of device screens and things like camera cutouts and Dynamic Islands. However, this implementation is buggy and only serves to push the video off to the right, which results in a weird black gap, and some of the video being cropped outside the container.

To see the bug, make sure you're visiting this page on a mobile device and in landscape orientation.

It doesn't matter how big the video is, or where it's placed.
